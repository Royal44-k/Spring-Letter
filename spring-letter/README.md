# 花漾年华：待寄出的春信

**0.9.1 · 花与花尘，随时可回**。一段关于照料、记忆与后来者的三维艺术探索旅途：一个情境序章、十二个主要环节，以及带着两封信驶向曙光的终章。雨幕温室、沉星天文台、云海花甸三处独立三维地图，均可真实行走探索。本作是独立主题，与金沙项目无关。

花庭的原有视觉互动一直保留：百合、重莲、鸢尾、星瓣四种花形，月银、流晶、粉瓷、琥珀、青釉五种光色。0.9.1 在扉页、顶部导航和地图里明确设置「花与花尘」入口；进入后直接显示花形、配色及「花的形体 / 尘的呼吸」切换。点花心或「化作花尘」后可以拖动写风，粒子沿用所选花色，漂游后自动缓缓复原。从旅途中进入，可以点击「回到刚才的旅途」恢复原地图、位置与信件；从扉页进入则返回扉页。

你是弥，从风暴后的花尘中醒来的送春者。守园人岑留下三封尚未回复的来信：禾想记住窗边等待春天的人，阿渡需要把信送过风廊，游絮则在旧杯声的停顿里，等你写下一段自己的回应。替他们回信之后，你会在海岸写下自己的话，趁退潮收起岑的旧信，到小岛寻找一叶舟。岸边留着你种下的春天，船把两封信带向远方。

0.9.0 在写信之前加入引蝶授粉、三维描星和角色花伞滑翔。三个地点分别拥有雨林温室、夜间遗址、云海浮岛的地形、地标、声景与保存状态；扉页的“展开远方地图”可直接前往，原有九段行动与海上结尾继续保留。亲笔信保存玩家实际输入，终章可以下载两封信。花桥可走花路及 0.7.1 的序章、水面、图形恢复与高分辨率缓冲区保护继续保留。具体实机检查与限制见 [FINAL_QA.md](FINAL_QA.md)，本说明不代替当前构建的验收证据。

## 开始游玩

在本目录双击 **启动春信.cmd**，然后打开 [本机花庭](http://127.0.0.1:5192/)。需要本机已有 Node.js；启动器优先使用 `D:/NodeJS/node.exe`，否则使用系统的 `node`。保持服务窗口开启；提示已复用同版服务时，可关闭新打开的窗口。

也可以在本目录运行：

```sh
node scripts/serve.cjs --open
```

发布版从 `dist` 提供文件，不要直接双击 `dist/index.html`。若 5192 已被不同版本占用，启动器会报告冲突，不会关闭已有服务。需要另开地址时，可运行 `node scripts/serve.cjs --port 5193`；不同端口的浏览器存档彼此独立。

游戏画面、音乐与素材由本地文件提供，无需账号、付费接口或远程游戏服务器。已有旅途请选择“续写春信”；“另起一封春信”会先确认并备份原旅途。

## 从花庭到远海

序章《借来的春天》介绍弥、游絮与岑留下的来信；可以跳过，按自己的节奏开始。地域地图连接旧花庭、三处驿路与海岸，“完整旅程”展示十二段主线进度。花卉散聚、追风与旧杯等自由支线不计入下表十二段。

| 环节 | 主要行动 |
|---|---|
| Ⅰ 花光暗房 | 摆放树、窗、花三张透光花笺，让故乡重新显影 |
| Ⅱ 纸翼渡风 | 连续控制纸翼的方向与高度，让信经过风门抵达 |
| Ⅲ 回声织信 | 编排、试听并留下自己的三声部八拍乐句 |
| Ⅳ 借花为桥 | 把花尘织成可走的路，在石台之间收回、重新编织 |
| Ⅴ 留下两处春天 | 搬运两枚种核，在三种未来中选择照料的两处 |
| Ⅵ 雨幕温室 | 按住招蝶、放缓脚步，让蝶群跟随到三丛兰花授粉 |
| Ⅶ 沉星天文台 | 走到观星台，点触或描过三维星点，连成信封星路 |
| Ⅷ 云海花甸 | 角色跳跃并展开花伞，逐岛滑翔落地，收好远风 |
| Ⅸ 写给未曾谋面的人 | 写下真实的收信人与正文，亲手落印封缄 |
| Ⅹ 潮汐留下的旧信 | 观察涨退潮，沿石脊到旧邮亭收信，再登上小岛 |
| Ⅺ 岸边的一叶舟 | 找到小舟，解开两侧缆绳、升起花帆，然后离岸 |
| Ⅻ 一路繁花向海 | 掌舵、调帆、撒下花种，在立体花景之间航行 |

终章《收信人，尚在远方》由玩家再次确认启程：两封信在同一只信袋里，船驶向晨光。结束页保留亲笔原文，可以保存两封信、留一帧远航、继续看海或重访花庭。

## 三封来信，三种行动

靠近春庭的来信入口，按 **E** 或点击“走近看看”。完成场景中的行动后，亲手选择回信才会保存作品并留下相应变化。已回信的场景会收起操作区；点击“再玩一会儿”可以展开、继续修改或重玩。

| 体验 | 你可以做什么 | 回信留下什么 |
|---|---|---|
| 花光暗房 · 把故乡放进光里 | 抓住三片透光花笺，移动、叠合到幕上的留影；观察树、窗与花逐层显现 | 留住树影，或让窗里开出新花；植物与投影构图随选择变化 |
| 纸翼渡风 · 把信折成翅膀 | 主动起航，连续调整左右与高度，借上升气流、应对侧风，穿过五道风门 | 点亮渡口的灯火与引航灯，或展开护种帆，照料篷下的幼种 |
| 回声织信 · 写一段没有旧稿的春声 | 点触或拖过三种乐器，在八拍里加入、移走音符，试听并撤回 | 保存自己的真实谱面，让新声陪伴旧曲，或把这段回应寄向远方 |

**花光暗房**：拖动花笺；`1 / 2 / 3` 选片，方向键移动，按住 `Shift` 微调，`Z` 撤回，`R` 重新布置。三片花笺各有可观察的目标轮廓，颜色之外也可凭形状判断。

**纸翼渡风**：点击“折翼起航”或按 `Enter`，随后拖动纸翼，或按住 `WASD / 方向键` 控制左右与升降。`Space` 收翼缓行，界面也提供“缓行”开关；触屏方向按钮可以持续按住。错过风门会回到上一段安全点，已经通过的风门保留，没有生命值或倒计时。“落回安全风段”会暂停；设置、离开与恢复存档后，需要主动继续起航。

**回声织信**：在场景里点触乐器可开关该音符；拖过多个乐器可以连续落音。`1 / 2 / 3` 选择声部，左右方向键选拍，上下方向键换声部，`Enter` 开关音符，`Space` 播放或停止，`Z` 撤回，`Delete / Backspace` 删除选中音符。至少留下三个音符、使用两种声部，并完整听过当前谱面一次，才能回信；修改后需要重新听一遍。

三庭之后，沿指引走向旧台，用风笔织出花桥，再将两枚种核安放到三种未来中的两种。可以预览安排、选择“再想一想”，取回种核后重新安放；确认后先经过三处新增驿路，再到海岸写自己的信。种核安排不直接结束整场旅途，结尾在海上。

## 三处远方，各有自己的走法

扉页“展开远方地图”或旅途中的地图按钮可以前往任一新地点；各地进度分别保存。新旅途在两枚种核安放后自然进入雨幕温室，完成三处驿路再衔接海岸。独立游览新地图不会自动完成旧花庭或解锁未做过的主线。

**雨幕温室**：穿过琥珀暖光、铜色拱架和巨蕨，按住 `Space` 或“招蝶”按钮，让蝶群靠近；保持慢行，将它们带到三丛兰花旁停留授粉。松手会结束招蝶。花朵舒展后留下「花香」。

**沉星天文台**：沿月白石阶走到观星台附近，按 `E` 或“仰望星空”进入观察。点触或拖过亮起的三维星点描出信封形星路；也可用 `1–6` 或屏幕星点按钮逐点连接。`Z / Backspace` 或“撤回一笔”撤销一步，“回到石阶”退出观察；可以中途离开，已描的星路会保存。完成留下「星路」。

**云海花甸**：角色本人在实体浮岛上行走，按 `Space` 起跳并持续按住展开花伞，用方向输入滑翔到下一座岛；松手收伞。触屏使用方向键和独立的“起跳 / 花伞”长按按钮。抵达新岛形成安全检查点，落空会回最近安全岛，已获得的进度保留。完成留下「远风」。

三处均可拖动环看、`C` 回正，并通过地图回访；回到扉页后选择“续写春信”可以继续所在地点。三种记忆在写信前回响，玩家自己的信与岑的旧信仍一起随船远航。

## 写信、过潮与出海

**亲笔信**：填写收信人与正文；“借一句开头”只给出可继续修改的起句，不会替玩家自动写完整封信。点击花印或把印章拖入信封完成封缄；离开书桌前可选“拆开，再改一笔”。确认“收好自己的信，走向潮脊”后，信随旅途保存。

**潮汐与旧邮亭**：`WASD / 方向键` 随镜头方向行走，`Shift` 轻跑；也可点击地面走近，或使用触屏方向按钮。低石在退潮时露出，高石可以停留等待；走进潮水会回到最近的安全高石，已经收好的信不会丢失。靠近中途旧邮亭按 `E` 或点击提示读信，再选“把这封信也带上”。读信或打开信袋时，行走与潮汐推进暂停；点击“先合上，看看潮水”或按 `Esc` 可合上旧信，稍后再读。

**岸边备舟**：带着两封信走到岛岸，靠近小舟按 `E` 登船。拖开两侧绳结，或按 `1 / 2`、点击对应按钮解缆。沿桅杆向下拉索，或按住 `Space`／触屏“拉索升帆”按钮升帆；松手即可停住。两侧缆绳都解开、花帆完全升起后，选择“让船接住风”离岸。

**海上航行**：`A / D` 或左右方向键掌舵，`Q / E` 调帆，`Space` 缓行，`F` 撒花种。鼠标可左右拖动掌舵、拖动帆角滑条、点击水面撒种；右键拖动环看，`C` 回正。触屏使用左右方向键、帆角滑条、撒种与缓行按钮。沿航路，莲、百合、鸢尾等立体花形在海面展开；走过的航迹会留下花，也可以主动点缀。航程没有生命值、计时死亡或强制刷分。

海岸与航海时，`B` 打开信袋，`Esc` 合上阅读面板或进入暂停设置；可随时用“重访花庭”返回，随后从地图续写海岸篇。到达曙光前，选择“带着两封信，驶向曙光”，或在场景中按 `Enter`，完成最后一次启程。

## 行走、花尘与声音

| 操作 | 作用 |
|---|---|
| `WASD / 方向键` | 在庭园中随镜头方向行走 |
| 按住 `Shift` | 踏风加速；慢下来恢复气息 |
| `E` | 进入附近体验、与物件互动、拾起或安放种核 |
| 拖动 / 滚轮 / `C` | 漫游时临时环看 / 缩放 / 镜头回正 |
| 近花时 `F` 或轻触花心 | 让花化作花尘，拖动写风，等待它缓缓复原 |
| `Space + 拖动`，或 `R` 开关风笔 | 在旧台沿光迹编织花桥 |
| 全屏按钮 / `Alt+Enter` | 进入或退出全屏；`Esc` 优先退出全屏 |

近看花朵时，触屏单指写风、双指环看与缩放。花卉保留四种花型与月银、流晶、粉瓷、琥珀、青釉五个视觉系列，花尘配色随花卉变化。可选追风、杯声、光痕与旧年支线仍可探索；它们不替代十二段主线。上表的风笔、滚轮与花心操作主要用于花庭；新驿路、海岸和船上以当下显示的操作为准。

首次点击进入后，浏览器才允许播放声音。配乐使用本地免费乐器采样演奏原创编排；脚步、摆放花笺、穿门、落音、织桥和安放种核有动作反馈。进入春声创作时，背景配乐淡出，为玩家的音符让出空间，退出后恢复。设置可分别调节配乐、动作音效与环境声；春声乐器由动作音效音量控制。菜单暂停、静音与作品试听的停止操作会处理正在播放的声音。

海岸篇另有写信、潮汐、登岛、备舟、航行、曙光和结束七段情境编排：落笔时留出稀疏钢琴与停顿，出海后转入有两组三拍重心的 6/8 航行乐句，曙光段再展开。离岸时会重现已保存的春声作品。封缄、翻纸、解缆、升帆与海上开花也各有反馈；海水底声由已有河流录音滤波、混合制成，没有新增收费音轨或冒称海洋实地录音。

新增三图分别使用木拨弦与疏落笛声、留出完整空白小节的钢琴与高竖琴、轻盈三拍流动乐句。旋律与节奏分别编写，乐器和自然录音继续使用已有免费 CC0 资源；没有新下载商业音乐、在线生成声音或新录制的雨林声。

## 留下自己的作品

来信册展示已经提交的三份“春信留影”，点击“收藏这一页”可在本机下载 **SVG**：

- 花光记录保存时三片花笺的位置与树影／新花选择。
- 纸翼记录风门通过情况和保存时的位置；它不是完整飞行轨迹录像。
- 春声花谱逐格对应三种声部、八拍中的真实音符与留白。

春声作品还可以在来信册里回听，播放时高亮对应拍位；它使用保存的谱面，不是固定配乐。再次点击停止，或关闭来信册，即可结束试听。编辑草稿不会立即改写已收藏的回信作品；需要重新完成并提交。

“留一帧春光”可以导出当前风景，或生成带回信选择的春信明信片。所有导出都在本机制作，不会自动发布到外部平台。

海岸信袋展示亲笔文字和已收下的岑旧信；结束页“收好这两封信”会下载 UTF-8 **TXT**，包含玩家填写的收信人、正文与岑的旧信。正文按纯文本处理，不作为 HTML 执行。亲笔内容随本机旅途存档保存，导出的 TXT、JSON 也含这些文字；没有加密云端信箱或自动联网寄送。“寄向远方”是游戏中的叙事行动，不会向真实邮箱或联系人发送内容。

## 存档与旧版本

旅途自动保存在当前浏览器、当前网址，不跨设备或地址同步。设置中的“旅途存档”可以导出 JSON、预览导入、恢复上一封或最近有效保存。多页面发生保存冲突时，先导出当前页，再决定读取哪一份。

**旧回信保留原来的选择与文字，新体验不会被自动标记完成。** 已经在 0.6 回过“浇老树”等旧信的玩家，可以保留原旅途继续游玩；只有亲手完成新体验并提交，才把该条记录更新为新回信与作品。已经寄出的旧结尾快照保留，不会随着后来编辑而改写。

0.7.x 及更早已经完成种核结局的旅途，选择“续写春信”可以接上新增海岸篇，从亲笔书桌开始；不需要清空旧档或重玩全部庭园。旧结尾记录与新增海岸进度分别保留，不会伪造玩家已经写过信、收过旧信或走完航海。写信草稿、旧信、备舟和航行进度会随保存恢复；潮脊恢复到已到达的安全高石，船保留已走航程并清除旧速度与按住状态。

0.8 的海岸或已结局存档保持原有位置、信件与结尾；0.9 的三处驿路作为新增可访问地图，未亲自完成的地点不会自动标记完成。观星线段与兰花进度可以继续，云岛空中存档会回到已到达的安全岛，避免恢复时继续坠落或残留按住状态。

浏览器不能保存时，可明确选择“临时游玩”。临时进度只在当前页内存中，刷新或关闭前需要导出；不会覆盖原有本机档案。试玩反馈也由玩家预览后自行下载，没有暗中上传或统计。

## 当前范围与限制

当前是可独立游玩的浏览器艺术探索章节。花光是三片花笺的有限空间谜题，纸翼是五道预设风门的连续航段，春声使用固定音阶、三声部与八拍；新增地图与潮汐、海航也有明确的地形边界和编排路线。十二种主线行动连接多个独立地点，仍不是无限开放世界、自由造景或完整作曲软件。

桌面浏览器是主要体验平台。触屏仿真、自动回归、截图与声音采集各自有边界，不能替代实体手机、不同显卡及陌生玩家的实际体验。首次准备复杂花型或视觉系列可能短暂停顿，未承诺所有设备全程 60 fps。角色、环境与演出仍采用当前规模的程序造型，未宣称参考视频逐像素一致、电影／AAA 制作水准或商业价值验证已经完成。

最终构建、已完成检查与遗留限制以 [FINAL_QA.md](FINAL_QA.md) 为准；不把旧候选的结果套用到当前发行版。

浏览器验收脚本用于已构建的静态页面，会同时核对 JavaScript 与 CSS；不以 Vite 热更新页作为发行证据。先运行 `npm run build` 与 `npm run preview`，再在另一 PowerShell 中设置 `$env:SPRING_URL="http://127.0.0.1:4192/"`，执行 `npm run qa:v12`、`npm run qa:v12:layout` 或 `npm run qa:v12:audio`。这些脚本依次运行，使用隔离浏览器，不读取或覆盖日常游玩的浏览器进度。
