# v7 可玩性复核：有了运动，但还没有足够多的决策

2026-11-20。范围：当前 `resonance-model.js`、`resonance.js`、`dash.js`、`exploration-model.js`、`story-model.js`、`story-director.js`、`layout.js` 与 `main.js` 接线的代码评审。**本次没有运行浏览器，也不是视觉、音质或玩家测试结论；全程普通输入验收仍由主任务执行。未修改 runtime。**

## 严厉结论

三庭仍是同一种“收集足量 → 回巢”的玩法变体。自由顺序、踏风、回巢结算和第三庭开合确实超过了按钮展示，但还不足以回应“没有可玩性”的核心反馈。第一庭可以作为教学；第二、第三庭应当至少有一庭改变玩家解决问题的方法，而不只是增加数量和等待窗口。

具体依据：

- **取舍较弱。** 三庭都是外围花灵、同一花巢、同样的结算与评分。75 / 80 / 90 秒是宽容时限；5.5 秒连锁窗口按步行速度 3.15 计算可行走约 17.3 米，超过单庭直径。此为几何估计，不是实际游玩计时，但说明“连锁”不能自然等同于技术挑战。三级和声只要求全收，与连锁、失误和时间无关。
- **踏风接近通用最优操作。** 踏风同时加速、免疫风结、收金灵；金灵又回补 0.32 能量，约抵消 0.84 秒踏风消耗。银灵也能踏风收取。风结在半径 2.9 米转动，大部分花灵在外围，沿外圈收集能减少与风险的接触。第三庭开合增加观察，但不改变“沿圈清空”的基本答案。
- **支线有动作差异，缺少互相影响。** 雨庭画固定圆、风庭按三个固定门牵种、潮庭依序停步；杯曲允许表达，刻痕是定点停留，旧花要求全合、全开后选中间范围。它们多数留下记录、花景或结尾文字，较少改变后续行走策略。旧花的“选择”尤其具有规定答案，不能把它描述成开放的道德抉择。两枚种核选三个愿望有主题潜力，但不能独自支撑整段游玩的趣味。

现阶段适合称为**正在完善的短篇艺术探索游戏**。没有证据支持“AAA”“电影级成品”“已经解决重复性”等交付措辞。

## 建议只推进以下三项，不再堆活动数量

### 1. 优先：第二庭改为护送，让移动产生关系

用现有风庭种子的惯性、关卡门和检查点规则，替换第二庭重复收点；第一庭保留作踏风教学。种子沿弥走过的短段花尘轨迹跟随，超过约 2 米便停下来呼唤。弥可以慢行领它绕开风结，也可先踏风穿过风结，使该处短暂平静，再带种子通过。冲得过远会错过平静窗口，立即折返仍能继续；种子不消失、不扣已有成果。

**决策改变：** 是贴近护送、走较长的安全弧线，还是暂时离开种子，去打开较短的通道？速度有用途，也有位置代价。用种子与披风间松紧变化的花尘、种子的靠近／等待动作和呼声解释状态，不新增按钮或面板。

**落点与验收：** 复用 `exploration-model.js` 的种子积分与检查点，给 `resonance-model.js` 增加护送状态；在风庭现有半径 6 米的可行走地面内布三门。先验证慢行绕路和踏风开路两种方法都能完成；暂停、落后、取消、重进不得丢永久进度。原风过庭支线必须相应缩短或改作可选进阶，避免把同一护送再强制做一次。此项改变规则，不能仅把花灵换成种子模型就算完成。

### 2. 小步可落地：第三庭让快、慢各有适用对象

保留现有金灵开合，但使银白花灵在近距离急风中合拢，慢行才接近；金灵仍在开放时踏风接住。合拢前先有可见收瓣和短促花铃，约 2 秒恢复，不没收已收花灵。把银灵成组放在内侧、金灵成组放在外侧，并保留宽阔通路，避免只增加刁钻碰撞。

**决策改变：** 先慢行接银灵、保留踏风能量，再抓外侧金灵窗口；或先追逐金灵连奏，再回内侧安静接花。持续按住 Shift 不再覆盖全部目标。已有 `requiresDash/open`、花冠开合、实例颜色和音效事件可承载规则，HUD 只更新既有一句提示。

**验收：** 不追求连锁、使用宽容窗口进行普通快慢切换能完成最低目标，熟练切换能全收；任何花都不能因一次误冲永久错失；仅视觉提示也能辨别规则，不能靠颜色或听觉单一通道。当前第三庭仅有 5 枚银灵、目标为 7，不能误称“全程步行也能完成”。最高分可以奖励良好切换，主线与最低完成奖励保持宽容。此项只能改善第三庭的节奏，不能代替第 1 项对重复结构的修正。

### 3. 次优先：让一条支线给出可运用的知识

先只接通潮生庭：听完三段回声后，第三庭的下一朵即将开放的金灵，提前约 1.2 秒发出有方向的回声与花瓣脉冲。玩家学到“听见呼唤 → 判断位置 → 决定是否赶去”，而非再得到一个完成勾。沿用现有回声位置、`tide.done` 与金灵相位，不增加技能栏、按钮或货币；未完成支线仍能看见正常开合并完成活动。

**决策改变：** 玩家可以绕路了解潮庭，换取后续安排路线的提前量；也可以直接前行，现场观察。支线收益成为可使用的线索，而不只在结尾文案中回收。

**验收：** 提前信号必须准确指向仍未收集的目标，暂停后不漂移；关闭声音也有相同提前量的视觉脉冲；普通路线不依赖该奖励。不要把所有支线同时改成数值加成，此处先证明一次有因果关系的探索回报。

## 执行边界

先完成当前候选的普通输入全程测试，再单独实现并验收第一项；第二项可作为下一小步，第三项在信号清晰后接入。增加粒子、乐器、场景摆件只能改善感受，不能拿它们替代规则差异、玩家选择及选择后的可见结果。以上均为待实施建议，不计入 v7 已交付能力。
