# 花漾年华：待寄出的春信

独立艺术探索游戏 **0.3.0 · 风笔与远行**。你是弥，一位由修复花尘孕育的新送春者。走过方舟的主路与春庭，把风写成道路，亲手决定两枚种核的去处。与金沙项目无关。

## 打开

双击本目录 **启动春信.cmd**，或运行 `npm run serve`，访问 **http://127.0.0.1:5192/**。已有页面请刷新。封面与顶部均有全屏体验入口，也可用 Alt+Enter；Esc 先退出全屏。

`dist` 中素材全部本地化，运行无需账号或外部生成服务。不要直接双击 dist/index.html，浏览器模块与HDR需经本机HTTP服务加载。启动器优先使用本机 D:/NodeJS/node.exe；其他设备需安装Node.js。本机地址只在这台电脑有效。

## 本轮体验

- **自由看与走**：默认拖动360°环看，镜头相对行走，滚轮缩放。厚石拱挡住视线时局部淡出，镜头避开坡面。
- **风笔**：慢提开花、快扫化尘，松手自然回流。粒子保留花的表面身份，粉蓝曲带、细丝与风迹一起响应。
- **三座新春庭**：西侧柳岸描环，东侧高岸护送种子，池畔绕路停步听三封信。真正可达、可重访，有软退和永久开花奖励。
- **实景手绘花桥**：从脚下起笔穿过悬光，松手成路；桥上不能拆掉承托自己的结构。
- **亲手送达的结尾**：拾起、携带、安放、取回种核，最后长按寄出。先看世界与同伴回应，再读回信；三种安排可以从安全节点重选。
- **旧内容继续保留**：六镜实时序章、三条物件支线、四份旧记录、拾光册、三种材质与本地留帧。

## 操作

|操作|作用|
|---|---|
|鼠标左拖或右拖 / 触屏单指拖|默认环看；启用风笔时右拖仍可环看|
|WASD / 方向键 / 屏幕方向盘|沿当前镜头方向走；Shift加快脚步|
|滚轮 / 触屏双指|拉近或远离|
|Space＋拖动 / R切换风笔|在实景中写风；触屏点击底部风笔再描画|
|近看花时慢慢上下运笔|开合花瓣；快速挥动扬起花尘，松手自然回流|
|E / 靠近·细看|近看物件、进入互动；终庭按住拾起、安放、取回与寄出|
|M / 花庭图|看路径、当前位置与送达情况，不传送|
|1 / 2 / 0|杯曲支线的左杯、右杯、留白|
|1 / 2 / 3|信笺支线的三处光束，也可实景移动指针|
|Esc|离开近看或打开设置；全屏时先退出全屏|

第一幕让花半开停留。第二幕从光后方轻推：鼠标无需按键，到杯边移远指针；触屏开启风笔拖动，到杯边抬指。第三幕在固定台间手绘花桥，第四幕把两枚种核送到三座花座中的两处。辅助花开滑杆、Shift＋滚轮和结构选项保留在二级面板。

所有进度保存在本浏览器。未安放的种核重新继续时回到终庭入口，已放下的用途保留。新三庭兼容既有v1存档。重演支庭不会清掉永久花景，也不会凭空给第三枚种核。

## 画质、声音与设备

轻盈档为16,384粒子，关闭额外水面镜像与接触遮蔽；均衡和细腻为65,536粒子。手机横竖屏与多指已经做浏览器触控仿真，不能替代真实手机设备验收。

声音全部由本地Web Audio合成。静音不隐藏文字与可见节奏；轻缓动态保留同样的任务规则。声音节点验证与实际听感评审分别记录。

## 开发

在本目录执行 `npm test`、`npm run build`。本机复用父目录已安装的开源依赖，复制源码到其他设备后需 `npm install`。不要在父级金沙项目执行本游戏构建。

普通输入检查：`npm run smoke`、`npm run qa:exploration`、`npm run qa:branches`。边界/视觉/声音：`npm run qa:boundary`、`npm run qa:visual`、`npm run qa:audio` 与 `node scripts/fullscreen-check.cjs`。用环境变量 SPRING_URL 指向待验收服务；每份报告记录具体URL和构建。`npm run qa:soak` 为长时间UI与资源运行检查，SPRING_SOAK_MINUTES可控制分钟数。

v4脚本与旧证据保留作历史资料，不能替代v5规则验收。测试不会为普通通关注入进度；明确标为故障边界的检查会注入坏存储、失焦或图形中断。
