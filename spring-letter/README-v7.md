# 花漾年华：待寄出的春信

**0.5.0 · 风起之时**。一段关于同行、等待和为后来者留春天的艺术探索旅途。独立主题，与金沙项目无关。

双击 **启动春信.cmd**，打开 http://127.0.0.1:5192/ 。需要本机已有 Node.js，启动器优先使用 D:/NodeJS/node.exe；保持服务窗口打开。不要直接打开 dist/index.html。

游戏素材全部在本地，无需账号、付费生成接口或远程游戏服务器。已有浏览器页面请刷新；选择“走进花庭”从新旅途开始，“续写春信”回到原位置。花型、声音偏好和个人最好成绩单独保存。

## 这一次，风有三种走法

- **第一阵春风**：自由选路接花灵。银灵走近即可，金灵需要踏风。接够五朵就能回巢；也可以多走一段，把八朵全部带回来。
- **风廊同行**：白蓝游絮跟着你。银灵需要你们靠近时一起接取；你可以先踏风去追金灵，然后放缓步伐等它跟上。回旋风会打断连奏，但不会丢失花灵。
- **把远方带回来**：银灵喜欢慢行；金灵需要在花冠展开时踏风接住。观察开合、切换快慢，再决定什么时候返回。

三庭都需要回到起点花巢按 E，才会留下成绩与新花。初庭首次回巢唤醒道路，风廊首次回巢带来同行者；原先花尘练习与游光路线仍然可以推进旅途。取消、超时和离开活动不会抹去主线进度。

## 行走与表达

| 操作 | 作用 |
|---|---|
| WASD / 方向键 | 随镜头方向行走 |
| 按住 Shift | 踏风加速；放缓步伐恢复气息，接花灵补充气息 |
| E | 花巢出发/回巢、附近物件、种核拾起/安放/取回 |
| 拖动 / 滚轮 / C | 临时环看 / 缩放 / 镜头回正 |
| 近花时 F 或轻触花心 | 化作花尘；按住拖动写风，静候它自然复原 |
| Space + 拖动，或 R 风笔 | 在旅途中沿光迹编织花桥 |
| 全屏按钮 / Alt+Enter | 全屏体验；Esc 优先退出全屏 |

触屏使用方向按钮，可同时按住“踏风”。近看花朵时单指写风，双指环看与缩放。桌面浏览器是主要体验平台；触控已做浏览器仿真检查，不能替代真实手机测试。

第一次点击进入后播放音乐。七个 CC0 真实乐器采样演奏原创乐段，庭园、追风、水庭与寄信采用不同配器和节奏；脚步、风笔、接取、织桥和安放种核有动作反馈。设置中可分别调节配乐、动作音效和环境声，菜单暂停与全局静音会真实停止/压低输出。

## 花庭中的内容

四幕主路、三庭追风、杯声/光痕/旧年三条物件支线、雨庭/风庭/潮庭三座探索春庭，以及由两枚种核形成的三种结尾。四种花型可搭配月银、流晶、粉瓷、琥珀、青釉五个视觉系列。首次进入默认为粉瓷；已有偏好继续保留。

晨空、石岸、细叶草簇和浅水为本地三维场景。石材使用登记的免费真实表面图；角色、花与关卡几何仍是原创程序造型。本作是可独立游玩的浏览器章节，没有把商业 3A 制作规模或参考视频逐像素一致性作为已达成的事实。
