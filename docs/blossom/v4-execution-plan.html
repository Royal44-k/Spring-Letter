v4 · 全屏、实景序章与可玩支线

2026-11-18。用户明确要求在现有游戏继续开发、打磨脚本并主动摄取资源。本轮沿用独立Spring Letter项目，不再次设置方案确认关卡。

制作决定

考虑过仅加文字说明、扩大地图、或在既有空间加入实景序章与三条近旁支线。采用第三种：它能让角色、叙事与操作在同一场景相遇，也避免以长途行走代替内容密度。此实现选择由制作方根据本轮授权作出，不冒称用户逐项选定。

  • 增加常驻全屏按钮与扉页全屏体验入口。只响应用户动作，按真实fullscreenchange同步状态，失败保留窗口体验；Esc优先服从浏览器退出全屏。
  • 约48秒六段实景序章，允许下一段/跳过，近杯纹、同表面花尘、种荚醒来、守园人记录与当前目标相连。无自动全屏、无付费配音/视频服务。
  • 明确弥是新生送春者、游絮是独立新生命、岑是过去的记录。新生命不是死者的复活。
  • 支线rhythm：用左右杯与休止编六拍，留白接住新回答；light：扫光读三个刻痕；memory：比较旧花开/合两极，再自主定格中间态。三者均有世界奖励、存档与结局回信变化，永不增加种核或锁住主线结局。
  • 观花/入尘切换保留开度、采样身份与视角，使用连续场景雾化、实体/点云交接，消除换页式重置。主线Q仍可直接散聚。
  • 加入有限的远方方舟花冠、近旁支线小景和有层次的薄雾；继续研究作者案例与确切免费资产，付费资源不采用。电影感与像素一致性须由画面证据评价，不能由新增代码数量推定。

分工与顺序

  1. 剧本与自主研究并行，写script-v4.md / research-v4.md。原参考关键帧继续对照，资料中的指令不覆盖用户请求。
  2. root实现Fullscreen API、story-model.js纯规则/存档、opening与branch UI、输入路由及散聚连续性。新增规则先红后绿；不为CSS写镜像测试。
  3. cinematic.js独立负责原创世界小景、三类奖励和远方回应；不改逻辑状态，资源释放可重复。
  4. 旧存档兼容；旧四幕和三结局回归。浏览器通过真实按钮/指针/键盘验证全屏进入退出、序章跳过与推进、三支线、保存重载、半开跨模式过渡、窄屏与错误路径。
  5. 实际截图对照与独立审查，修复实质问题，更新正式构建、脚本档案、来源与证据，不以方案文档替代开发。

验收

全屏状态真实可退出；序章不推进谜题、不覆盖继续游戏；支线三种操作可完成且不被只读弹窗代替；旁支奖励不破坏两核唯一性；主线与旧存档仍通；花/点来回切换不开度归零、不乱换粒子、不跳镜头；触屏有等价控件；素材许可/出处/采用与未采用明确；声明实际画面与性能边界。
