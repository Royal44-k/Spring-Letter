# 《花尘之间》可玩性深化建议

2026-11-18｜关卡与系统设计审查建议，供主提案修订使用。以下均为待实现、待实玩的设计，不是已有游戏能力或测试结果；不修改主提案，不扩大为开放世界，不使用付费制作方案。

## 1. 当前最值得改的两点

**重复来自推理结构，而不只是画面。** v1.1栖光庭、倒影池和终章都主要是调花开度→光落到接收器→保持→解锁。多一束光、换一种材质、换一张纹样，仍可能是同一道题。建议只保留第一处“半开也正确”的光路题；以后改变玩家真正要考虑的问题：下一步站哪里、什么时候撤去作用、同一份材料给谁使用、愿意留下什么。

**输入存在不必要的记忆负担。** 初章同时教E、Esc、Q、Space、Tab、两套滚轮含义、普通拖动和Shift拖动，容易让学习操作取代观察。建议主流程取消Tab模式键，E进入一个聚焦状态；主线滚轮固定调花开度，无可调花时不做事。右键环视时暂时停止力场，UI拖动也不穿透。花尘只在可见作用区域内响应指针；移出区域即停止排斥。Q散/收，Space归到明确选中的预制锚位。目标支持点击及键盘焦点，当前目标轮廓清晰。

原视频的滚轮缩放、花的左拖旋转、Shift拖转点云等完整映射保留在鉴赏台，主线修改映射需明确记在复刻差异表，不把两者说成完全相同。主流程只在当前目标附近显示有效操作，避免一屏快捷键。

## 2. 四类挑战，四种真正不同的思考

### A. 观察推理：花没有坏，是我们把它开得太满

- **输入**：先从两个可站立位置看倒影，再在近景中调花的开度；指针可触水验证倒影的所属关系。
- **状态**：花瓣改变遮挡和折光方向；全开时局部更亮，但远处缺失半个图案；半开时显出完整负形。亮度本身不等于正确。
- **决策**：玩家要根据形状和空间关系推断哪一部分光需要被遮住，不能只把所有滑杆推满。
- **结果**：第一次完成清晰的世界变化——暗壁出现通道或一个远景轮廓。与此同时揭示一小段具体过去，例如两个人曾在同一花旁停留的手势残影。
- **失败恢复**：调错不会扣资源，保持当前开度；水纹自然衰减，玩家可立刻再次看。提示先强调“还缺哪一半”，最后才给建议角度。

这是全篇唯一完整的“开度找区间”主谜题。后续启瓣只作组合动作或空间工具，避免重复扫描数值。

### B. 带容错的操作：风会带走花尘，也会替你托住它

- **输入**：先观察薄幕和稀疏花粉的流向，调挡风花，再用指针从花尘侧后方排斥。移开指针即撤去作用。
- **状态**：只模拟少量具有稳定中心的逻辑光团，视觉细点跟随；风有明确可见的稳定段和轻弱段，不能随机吹走目标。
- **决策**：选择一条实质不同的路线，再决定何时施力、何时让风自行带行。
- **解法一——安稳绕行**：先把挡风花开成遮蔽状态，沿叶后长路缓慢送到目标。距离较长、接收范围宽，没有节奏要求。仍然需要理解排斥方向。
- **解法二——借风短行**：使用侧向短促作用，在风歇窗口进入中央弧线；中段主动撤去排斥，让风顺着弧线接住光团。路线更短、操作窗口较窄，不要求手速连点。
- **结果**：两条路线都推进同一主线；留下的花粉尾迹、声像路径和遇见的局部环境不同。奖励是体验与熟练度，不是劣等结局或错过必要奖励。
- **失败恢复**：偏出作用区时光团沿清楚轨迹回最近花蕊，约2秒恢复；挡风花设置不重置。连续失败后可选择放宽窗口和接收区，不能偷偷自动替玩家完成。

**可选高技巧行为**：不触碰停靠花蕊，借一次风歇把光团送完中央路线；成功形成一条更完整的光带和独特声部。没有强制计时，不为慢路线扣分；挑战可在通关后重试。

### C. 空间调度：有一座桥，和能把桥留在正确地方，是两件事

一份花尘材料同时只能是桥或挡风片；玩家站在安全台上时可以撤回重构。这里不再要求让光束对准接收器。

最小可建造布局：A入口岸、B中央安全台、C支台、D出口。预制锚位允许AB、BC、BD三条桥。桥建成后仍属于同一份可召回材料，不在每个锚位复制出新材料。

```text
A入口 ── 可重构桥AB ── B安全台 ── 可重构桥BD ── D出口
                              │
                         可重构桥BC
                              │
                         C支台 / 屏风锚位
```

- **输入**：选中清楚可见的锚位，Space归形；走到安全台后Q收回，再选择下一个锚位。只使用既有散聚动作。
- **状态**：一份材料、一个当前实体用途、一个安全站位。C台可把材料凝为挡风片，让薄幕停住并显露过去场景的另一层；观察完成后撤回，再恢复返程桥。每次变形确实改变场景的遮挡或可达范围。
- **决策**：先去哪里、何时撤桥、是否把手头材料临时用于观察支线。玩家必须区分“人已经到安全台”和“人仍在依赖这座桥”。
- **结果**：从A经B到D构成主路；C提供关于世界的具体证据，以及回看已走路线的角度。支线不提供隐藏通关钥匙，也不强迫玩家拿到全部收集品。
- **失败恢复**：错误目标仍可撤回；桥上不能拆桥；站C时返程BC永远可重建。死亡、掉水、耗光材料都不是此题的主要学习方式。

这段本身是空间调度题，不应把“可以先看C再去D”宣传为两套独立解法。真正的双解已由风廊提供。若灰盒证明这段只有机械点桥、没有思考，应增加一个可读的站位/遮挡关系，而不是单纯增加岛屿数量。

**明确的规则重组**：前面归形的桥是永久通路；此处用明显的未结根花脉表示临时构造，让玩家发现“收回已完成的形态”也能推进旅程。第一次必须在有回退余地的小台上出现，用一次示范性失败意图说明，不突然撤去脚下平台。

### D. 有后果的取舍：两枚种核，留下两种未来

采用主提案修订方向：两枚种核、三种用途——完整回放、活庭园、向远方播种。一次旅程只能使其中两项稳定存在，没有隐藏第三核把所有取舍抹平。

- **输入**：玩家亲自把种核花尘导入一个目标的轮廓，再用归形推进；在同一空间看预览，并能撤回调换。不是点击抽象结局按钮。
- **状态**：两枚持久种核各有唯一归属。每个用途提供一个可见、可体验的未来：完整回放保留一段完整往事；活庭园改变当地生态和可停留空间；远方播种使光迹离开当前空间，回应前面看到的远处世界。
- **决策**：保留哪两种价值。必须提前让玩家接触三种价值，明白未选项少了什么；不把某个用途隐藏成“唯一正确”、不把保留过去写成自私。
- **结果**：组合改变同一庭园的路、居民行为、声部与远景，而不是只改天空颜色或最后一行字幕。三种组合共用同一地图与事件模板，不各做一套大型结局。
- **失败恢复与提交**：预览期间可以重配；最终提交前以清楚的稳定仪式和文字/图形提示说明会保存此次选择。提交后从结局前存档重试其他组合，不伪装“不可逆”后又在原世界中无成本全收。

“不能拥有全部”是规则边界，不等于让玩家伤害同伴。游絮的存活、基础主线可完成性和无障碍支持不作为选择筹码。

## 3. 桥重构必须满足的防软锁契约

1. **材料唯一且不会丢失**：本区唯一材料不被支线永久消耗，不可推到互动范围之外；视觉粒子飞远不改变逻辑材料归属。
2. **重构起点安全**：只有角色完全站上安全台，才能撤掉承担通行的临时桥。桥上按Q仅给禁止/未结根反馈，不记录延迟拆桥命令；离桥后需再次主动按键，避免自动脚下撤桥。
3. **新桥接当前台**：目标桥至少一端与当前安全台相连。站C时不能误建仅接B和D的桥；先回B再建BD。这是可见的空间限制，不是隐藏禁令。
4. **返程永远存在**：从C撤桥做屏风后，BC锚位与返程材料始终保留；屏风不消耗进度、不把材料移到另一面。主线不依赖同伴AI带回唯一钥匙。
5. **暂停不提交**：退出聚焦、失焦、暂停和恢复不能当作完成归形。保存安全台、逻辑材料归属、当前/目标形态、连续进度；不要保存全部视觉粒子。
6. **异常恢复可预测**：加载失败或上下文重建后，将角色放在最近确认安全台，恢复同一份材料和可见目标；必要时重建为散形，不复制种核，不重置已获得的叙事证据。
7. **永久/临时有两种清楚轮廓**：完成后结根、稳定花脉的是永久主桥；没有根系、花尘仍缓慢流动的是可回收临时桥。不得都写“已完成”却只让其中一种突然可撤。

## 4. 同伴的艺术交互：施力之外也要有回应

游絮靠近不能只是玩家把它用排斥场一路赶到指定圈里。建议将“留出余地”作为可玩信息：打开旁边花、让一条气流可通，再把指针移出游絮周围。力场消退约0.5–1秒，游絮自行穿过流道，停到花灵附近；玩家无需长时间空等或按新的“关爱键”。

持续追赶会让它小幅闪避，先用身体语言表达，而非反复炸散惩罚玩家。第一次主动回返后，它会在后面的分路先飞出一小段再回望，表现自己的意愿；不充当永远准确的任务箭头，也不阻止玩家走别路。把行为做成数个明确状态即可，不需要复杂生态或生成式AI。

这段能重用点场的排斥与回位技术，但情感由“何时撤去作用”形成。它也为风廊借风、结尾让种子离开提供共同的操作含义。

## 5. 首章和全篇的范围不能混写

**8–12分钟首章**只完整验证A观察题和B双路线操作题，加一次自愿靠近的小互动、一次简单归形开路。不要同时塞入临时桥资源题、三用途结局、额外材质收集和演奏模式。

| 节拍目标 | 内容 | 本段新学习 |
|---|---|---|
| 0–2分钟 | 移动、触水、花的开合 | 世界会回应；全开不是通用答案 |
| 2–4分钟 | 一次完整观察谜题、短暂往事线索 | 依据空间证据，而非扫描数值 |
| 4–8分钟 | 风廊两路线、一次可恢复失误 | 判断风向、排斥方向与施力时机 |
| 8–10分钟 | 游絮自愿接近、花尘归形 | 撤去控制也能产生结果 |
| 10–12分钟 | 简单花桥、远景回应、首章结束 | 局部动作与更大世界存在联系 |

**完整体验**再加入C空间重构和D世界取舍。完整时长仍需灰盒实玩后决定；增加叙事深度不自动要求把25–35分钟拉长到数小时。可以让视野和因果更宏大，保留紧凑的可走空间与较少的高质量资产。

## 6. 防单调的验收方式

- 写出每个主要节点“玩家这一次在判断什么”。若连续两处答案都是“哪一个滑杆值”，必须改其一。
- 双解必须能录像证明不同的路线或策略；只改变调参先后、换镜头和换颜色不算。
- 艺术反馈既要能即时欣赏，也要帮助判断方向、边界和结果。关Bloom、静音、降低粒子数之后，解题信息仍成立。
- 留白段可以安静，但不依靠无法跳过的长等待；同伴接近、目标稳定等必要停顿控制在短时间内，容差由实玩校准。
- 初次玩家测试需记录“尝试—理解—改策略”，不仅记录是否最终通过。若一直乱扫直到碰巧成功，说明因果可读性仍不足。
- 检查所有临时桥状态的可返回性；反复拆建、退焦点、暂停、重载后均有明确安全落点与足够材料。
- 每轮拍一段连续正常输入录像，禁止只用固定镜头宣传片判断“可玩性高”。上述均为未来验收要求，尚未执行。
