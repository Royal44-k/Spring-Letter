# 风起之时 Implementation Plan

**Goal:** 把单次展示互动扩展为有技巧和可重玩的行动循环，补齐情境音乐及场景质感。
**Architecture:** 主程序接线；resonance独立规则与渲染；audio保留兼容接口重做音景；world-polish与atmosphere合批美术；dash负责移动资源。沿用旧存档，新增个人记录独立保存。
**Tech Stack:** Three.js、Vite、Web Audio、本地免费素材、Node测试、隔离Playwright。
**Spec:** [设计](v7-design.md)。用户已明确授权自主决策与制作，不再等待方案确认。

- [x] 回顾反馈、阅读旧代码和设计；备份0.4源与发行物。
- [x] 新活动模型：三处空间、不同路线机制、失误恢复、重复游玩与个人记录。
- [x] 踏风资源与连贯移动、角色动作、可读且不遮挡的活动界面。
- [x] 情境BGM、环境层、脚步与动作声音，音量/暂停/静音闭环。
- [x] 晨光材质、植被/远景层次、动景；来源与性能预算。
- [x] 主程序连接玩法、叙事奖励、音画变化，保留参考花与旧主线。
- [x] 普通输入新活动及旧主线回归，实际音频输出、实景截图与资源持续检查。
- [x] 完成后更新本机发行、说明和图文页，明确真实范围与后续差距。

评审重点：起始目标是否明确、连锁是否有实质取舍、跨边界碰撞、暂停/恢复、旧存档、音频自主启动限制、响度削波、景物遮挡和增加的绘制成本。验证有针对性，不重复45分钟等已不对应新玩法的旧流程来替代体验验收。
