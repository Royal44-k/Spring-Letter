持续运行与启动

本机设备：ANGLE (AMD, AMD Radeon(TM) Graphics (0x00001681) Direct3D11 vs_5_0 ps_5_0, D3D11)。持续 47.00 分钟，13 轮，351 段稳态采样。每轮以真实控件切换四形×五系列、反复打散归形、环看缩放、切换 65,536/16,384 粒子、静音与暂停后继续。

稳态各段平均帧间隔的中位数为 16.69 ms；各段 P95 范围 16.80–33.60 ms；稳态最大单帧间隔 50.50 ms。切换窗口单列，最大 183.60 ms。以上为同一共享桌面机器的 RAF 间隔，不是 GPU 定时查询，也不是隔离硬件实验室数据，不能当成所有机型的帧率承诺。

资源检查以完整首轮暖机后的固定状态为基线，比较以后所有同状态样本，并拒绝逐轮上升趋势；不靠“最后三次看起来接近”推断稳定。每段必须有新渲染帧，暂停则实际停帧并清除前景声音。完整计数、范围及局限；这仍不是显存泄漏的数学证明。

最终界面复核这次的加载准备 15.7 秒，其中光影准备 12.8 秒。历史独立实验在实际后处理目标上预热，约 32–33 秒降到 16–17 秒；该实验的首次换流晶为几十毫秒量级，删掉其他系列预热的对照则首次换晶约 2.4 秒，故舍弃。此段历史实验不是最终构建的首交互帧时结果；最终构建只以本页绑定报告为准。没有清除驱动缓存，不宣称全新驱动冷启动测试。实际耗时依设备与缓存变化。

明确的边界

这是风格化浏览器可玩章节。流晶厚度与内部折射、原片粒子折叠纱面感、石材与角色表现、长期玩法深度仍有差距；四花型目前主要改变观感。未进行实体手机、跨 GPU 或外部新玩家盲测，触控报告是浏览器仿真。参考视频有全帧解码联系表与关键帧放大，不宣称每帧原尺寸逐一审阅或完全复刻。电影感与商业 AAA 规模不由制作时长、截图或检查数量证明。
