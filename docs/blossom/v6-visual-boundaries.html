0.4 视觉复核：已靠近什么，仍差在哪里

本次结论来自原片截帧、隔离花卉实验图与实际主游戏截图的人工阅读。0.4 已建立四种可辨的花形、五组共同配色，以及从实体到花尘再归形的连续关系；目前适合称为有完整可玩流程的风格化浏览器作品，尚未达到参考片的光学精度，也不能按电影或商业 AAA 成品验收。

五个维度的对照

维度0.4 实做改善仍有差距与下一次应验证的内容
轮廓原百合保留三朵主花与花蕾的构图。重莲改为多层杯形瓣与圆叶；鸢尾有三枚窄旗瓣、三枚宽垂瓣与剑叶；大丽采用多圈卷瓣形成放射花盘。联系表中四者已能从整体剪影区分。原片百合的宽瓣更饱满，弯折连接更柔和。现有百合仍有薄片、尖角和折面感；多花相叠处会吞没局部花心。下一步应先检查中远景黑白剪影与花瓣相交，再增加细节。
厚度与材质流晶从过淡或浓紫的版本改为冰蓝内色，轮廓更易读；金属、粉瓷、琥珀色与青釉色形成不同反光倾向。实体与粒子共用配色来源。原片流晶是厚、圆、具有内外反射层次的体积。当前冰蓝流晶在日夜实验图中仍容易读成蓝色釉面或薄亮壳。材质参数中的 transmission、thickness 不能替代真实可见的体积；需要更圆润的几何、背面关系、厚薄变化和可控折射背景。琥珀与青釉目前是视觉系列名，不等于物理材质复原。
光照与画面层次主世界已有水面反射、远景雾化、近远植被、门廊与不同用途的花座。角色行走与花桥使画面拥有空间行动，超出了孤立花卉展示。原片暗背景集中托出花瓣亮边和内部折射；主游戏第一幕有植被、拱门、杯盏和水纹同时争夺注意。桥与终庭的浅色石面仍显平、硬、统一；角色和叶片也保留明显程序几何感。应优先控制花背后的明暗面、降低附近小物的亮度竞争，并拉开石材、叶片、衣料的粗糙度层次。继续加泛光不能解决这些问题。
运动与形态已有破开、漂游、低速牵流、高速扫动、延时归形；松手后有完整回程。稳定源采样让花尘回到当前花型，换色无需重置运动。实际第一幕截图中的花尘更像密度较均匀的点云；原片粒子更像连续折叠的纱面，轮廓有细密层叠和大尺度空隙。隔离进程图能显示运动阶段，不能证明手感、全场景稳定帧率或局部速度分布已一致。下一步应针对纱面连续性、疏密变化、卷边与静止区域组织做同机位短片对照，避免只提高粒子数。
色彩月银的粉色花冠、蓝色下部对应原粒子片的身份；流晶、粉瓷、琥珀、青釉分别保有自己的颜色。花枝与花瓣按不同角色取色，未用一个全局渐变覆盖五系列。主游戏第一幕中粉蓝两域可以辨认。原片的局部亮度变化、冷暖交叠和透光色更丰富。当前尘云大面积中间色偏均匀，部分远景与背景仍接近；实验黑背景中的色彩差别不等于日景世界中的差别。需要逐系列在浅地面、深植被、水面三个背景前检查，并保持主花身份。

三张主游戏图给出的实际提醒

第一幕写风的粉蓝尘云已能与紫色环境分离，但云团中部仍较实、点粒较均匀。花背后的大拱门和左侧叶片切割画面，水中小件的反光也很醒目。若继续精修，这里应先给花留出更安静的明暗背景，再决定哪些环境细节值得保留。

花桥截图能读出送信人、相邻石台、通向终庭的路径与远处三种花座。近处门廊制造了前景，但占据左侧很大面积；桥瓣和石台仍偏整齐的几何板片。空间路线是有效的，材质老化、接触阴影和近景造型还没有达到电影布景的密度。

已种植的旧日之灯有清楚的光环、文字与地面变化，能表达一次实际选择。终庭仍同时展示花座标签、步数指引、右下说明与字幕，画面的留白被信息占用。下一步应按接近、持有、种植后的状态分配信息权重；这属于叙事呈现与可读性共同的问题，不能只用更漂亮的面板替换。

不应被实验图掩盖的边界

  • 55 张花卉实验图用于比较造型、配色和局部材质。它们没有证明整个游戏拥有同样的光学效果，也没有代表全部机型。
  • 原片画面中的帧率和粒子数属于原作者的画面信息，未作为本作性能指标。浏览器的 RAF 间隔与资源计数也不是 GPU 耗时或显存测量。
  • 四种形态确实增加了视觉差异，但花形与系列选择目前主要改变外观，没有形成四套不同的玩法策略。
  • 已有多幕主线、叙事支线和探索庭，但场景与角色仍以程序化资产为主。复杂演出、完整角色表演、系统化生态与大规模内容生产尚未具备。
  • 电影感需要镜头、比例、材质、声音、留白和节奏共同成立。现阶段的进一步提升，应围绕少量关键镜头和可感知的互动结果逐项完成，而不是添加“AAA”标签。

后续工作可从两个明确选择开始：一是制作一个同机位的“厚流晶—碎为纱面—缓慢归形”质量样片，验证参考一致性；二是让现有花形或种核选择实际改变一处探索路径或环境反馈，验证玩法深度。两项均是下一阶段建议，不是本版已实现内容。当前完整实装范围见可执行剧情与交互脚本，技术取舍见制作复盘。
