## 接口

`snapshot.escort` 以及 `snapshot.run.escort` 提供独立副本，字段为 `x / z / distance / near / moving / waiting`，无护送活动时为 `null`。`context.escortNear / escortDistance / movementRule` 可用于既有 HUD；`context.hint` 会用自然语言解释等待、合流或快慢区别。

每个 `snapshot.nodes[]` 新增 `requiresEscort / requiresWalking / available / blockedReason`，保留 `requiresDash / open / collected`。`available` 表示当前运动状态满足规则，不代替实际接近、移动与未收集检查。`blockedReason` 为 `escort / walking / dash / closed / null`。拒收使用现有 `hint` 事件，并附 `reason`、`node`；同原因限频，原因变化立即说明。`start.text` 已按庭给出不同引导，主接线应使用该文本。

目标数量、限时、回巢结算、评分、永久纪录与既有存档键保持。游絮状态只属于本次活动，不会写入永久纪录；暂停冻结它，取消或结束移除它。这里没有增加游絮受伤、掉落花灵或新的强制失败条件。
