# v8 弥：衣料与邮袋精修

2026-11-21。本轮首先查看 `spring-letter/evidence/v8/third-look/dev-rain-arrival.png`、`dev-rain-board.png`，随后阅读原 `courier.js`。修改限于角色模块及对应测试，没有启动浏览器或 GPU；尚未看过本轮角色修改后的实机图。

原布衣材质没有 emissive。截图中发白的原因不能误写成衣料自发光；本轮针对其高明度统一表面、较光滑反光和缺少服装分层作调整。

## 已实施的形体与材质

- 保留原披风、头部、帽尖、四肢、围巾和手杖的主体几何、角色比例与组坐标。披风添加 UV、细织纹、苔绿分片及沿原曲面缝制的收边；内衬与围巾采用低饱和藕紫。
- 原背部信件位置改为帆布邮袋，露出信封、折线与封蜡；增加袖口、兜帽滚边及袋带，细线合并为少量网格。
- 所有布料 roughness = 0.92、metalness = 0、emissive 为黑。黄铜更旧、更哑光；脸部保持原来的简单形体与双眼，没有增添面部特征。眼与笔尖分离材质，避免原先写字反馈使眼睛一起变粉；笔尖仅保留 0.12 emissiveIntensity。
- 使用原创本地生成的 128 × 128 织纹颜色图和法线图，具有 mipmap；不下载资产，不依赖付费服务。
- 原行走、脚步、身体起伏、披风摆动与围巾轨迹不变。邮袋增加最高 0.035 弧度的滞后摆动，帽尖最高增加 0.018 弧度弯动，保持在旧角色运动外包围之内。

`node --test tests/courier.test.js tests/travel-camera.test.js tests/dash.test.js`：13 项通过。新增测试覆盖主体轮廓、脚底轨迹、运动包围、UV、资源预算、异常输入、眼部材质隔离及幂等释放。
