# 0.9.0 · 春信远方地图设计

2026-11-23。针对用户明确反馈：九个操作环节不等于九个新地图，必须增加真实地点、独立视觉主题和不同互动。延续已授权的自主构思、调研、实现与验收，不重复索要设计许可。与金沙无关，沿用本机浏览器 Three.js 工程，免费且本地运行。

## 取舍

比较三种方式：扩建旧花庭会保留同质空间；重做全开放世界会使资产与验证范围失控；增加三处独立可探索地图能提供明确的新空间并保留原作。采用第三种。地点不是二维弹窗或旧圆盘换色，每处必须有不同平面拓扑、完整三维地形、可走区域、独特地标、前中远景植物、声景、核心玩法与保存状态。

## 地点与玩法

1. **雨幕温室 / conservatory**：废弃温室被雨林重新接管。24–36米宽、约50米纵深的非圆盘空间，铜色拱架、玻璃残片、巨大蕨叶、兰花、高处悬根、雨线和暖光。玩家按住招蝶、放缓脚步，带一群有滞后与亲近距离的蝶穿行，依次或自由为三丛不同花授粉；追求陪伴和观察，不再转轮或取水。完成得到「花香」。
2. **沉星天文台 / observatory**：夜蓝玄武岩与月白石阶，破碎柱列、巨大黄铜浑仪、云隙月亮、白色夜花，马蹄形广场和高处观星平台。玩家走到观星点，进入仰望构图，实际点击/拖过三维星点描出信封形星路；允许中途松手、撤回一步、退出后继续，键盘提供等价逐点输入。完成得到「星路」。
3. **云海花甸 / meadow**：粉珊瑚与青绿草甸，多个实体分离的浮岛、垂根、低矮花丘、风旗、风车式雕塑与远方山峰。角色本身跳跃并展开花伞滑翔跨过缺口，逐岛形成检查点；落空温柔回到最近安全岛，不丢物品。没有复用纸翼小游戏。完成得到「远风」。

角色尺度沿用约1.1米，环境以能让人看懂的三维比例构建。主视角跟随移动，可拖动环看与回正。触屏保留方向、独立动作和清楚的继续入口。每地含可发现的短叙事布景，说明岑曾经经过这里，不用长对话打断行动。

## 叙事与入口

新主线：导入 → 原五段花庭 → 雨幕温室 → 沉星天文台 → 云海花甸 → 写自己的信 → 潮汐旧信 → 登岛备舟 → 花海航行 → 结局。共12个主要环节，不把布景或按钮凑作新关卡。

三个地点是送信前经过的驿路：先学会等待生命，再给远行辨认方向，最后信任风。获得的花香、星路、远风在地图记录与写信前提示中回响。结局仍为携两封信驶向曙光，海上有不同3D繁花。

地图改为地域地图，区分旧花庭、新三处驿路和海岸。已开始的旅途可从地图前往三处新地点，无需重做旧关卡；旧版已在海岸或已结局的存档保持当前位置和信件，新区域作为新增可访问旅程。新旅途在安放两颗种核后自然顺接三处地图，再进入写信。

## 工程约束

- 新 atlas-model.js 管状态与规则，atlas-content.js 是坐标、区域与叙事唯一来源；atlas-world.js 管新几何与动态；atlas-controller.js 管 UI/输入/相机；main.js 做场景切换。
- 只激活一个独立世界，旧花庭/海岸与新增地点互斥呈现；进入前有明确地点标题与短淡入，旧世界不穿透背景。不增加付费依赖。
- 保存顶层version仍为1；新增atlas嵌套字段严格normalize、有限数值、白名单地点；旧档无字段时补默认，不篡改已完成结局。
- 现有序章粉屏修复、全屏、存档导入导出和故障恢复继续回归。
- 避免大透明墙、负输入分数幂、共面闪烁、无界粒子/对象增长。布景不得占据必经路或遮住角色；模型几何与步行边界统一。

## 可验收结果

每处分别保存入口、互动中、完成后三张实际游戏截图，检查鲜明的环境差异；真实输入完成全部新机制、返回/重进/刷新、旧档兼容、地图入口与衔接；横竖屏和三档画质检查；声音实际输出检查；长运行检查对象数量不增长。最终将发布构建、测试记录、静态资源校验和离线包绑定同一版本。真人趣味评价和全设备商业认证不冒充自动化结论。
