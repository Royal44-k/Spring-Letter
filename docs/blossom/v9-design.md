# 春信 0.7：折光、渡风、织声

本轮由用户明确授权自主研究与重构。独立于金沙，无付费资产或服务。保留参考花卉/粒子、跟随镜头、全屏、本地声音、存档保护；撤下三庭重复转轮主线及同地点旧活动的重叠呈现。

## 方向选择

增加转轮条件仍然重复；把旧支线提为主线也不足以带来新意。选择三种不同的身体动作与注意力：静态空间实验→连续运动→有个人结果的创作。采用现有Three.js与原创程序几何，避免临时更换引擎牺牲可验证交付。

## 三幕

1. **花光暗房**：禾把故乡的花园压在三片半透明花笺里。抓取花笺在光场中摆放，看投影与图层如何相遇；显影逐层长出树冠、窗与新芽。直接操作三维物体，有接近时的形状/轮廓提示，键盘移动与撤回可替代拖拽。不是点一下依次自动完成。完成后可留下老树或新芽的构图。
2. **纸翼渡风**：把阿渡的春信折成纸翼，连续控制左右与升降，在纵深流动的风廊中借上升气流，滑过不同高度的风门、绕开侧风。失误回安全风段，无生命/倒计时惩罚。途中丝带和花尘响应飞行，最终抵达渡口；保存检查点与落点，不保存完整历史轨迹。主动起飞，可随时落回岸边；暂停/退出不残留输入。
3. **回声织信**：水上悬着八拍时光和三种可辨形状的声源。放入、移走、试听、拖奏，组合一段自己的回应。节拍不考反应速度，空拍也有意义；至少两种声源、三个落点，完整听过一次再封存。花铃/水纹/星图跟真实调度同步，结尾留存实际作品，而非统一音效。

三幕分别采用光学装置/空中风廊/水上乐器的轮廓，不再复制石盘。面板减为场景标题、当前动作和可收起来信。空间负责主要表达，文本补足人物需要。场景内反馈先于回信按钮。

## 架构与边界

每幕独立module：group、local bounds、update、pointer/key/action、snapshot、restore。通用controller只负责进入/退出/引导/保存/回信，不把三种规则抽成同一转子模型。每幕以本地坐标工作，组定位到已有三庭；渲染不掌管持久化。

moments独立状态保存草稿/完成；旧letters.choice与lettersSent继续保留。新增edition=2区分新回信，旧回信文本不改写。回信事务先保存候选，再确认奖励/演出。拖动仅结束时保存，演奏步骤不每帧写盘。新版本不能用旧已回信伪造新玩法完成。

侧边浏览器已成功打开七个官方案例：COCOON、Jusant、Chicory、Botany Manor、Gorogoa、A Short Hike、SEASON。Viewfinder 的侧边页出现 ERR_CONNECTION_CLOSED，未计入成功打开数；其官方与开发者网页资料仍作为研究文档中的第八项来源。只研究公开内容，不购买游戏/素材，不将案例截图或音乐打包。最终普通输入需走通三种实际机制、保存重载、暂停与触屏；测试通过不等于真人兴趣或3A质量。
