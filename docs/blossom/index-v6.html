同一花庭 · 两种连续状态

  1. 约 0.7 秒

    轻触，破开

    触碰花体、按 F，或用一次疾扫。花瓣表面成为花尘，颜色跟随所选系列。

  2. 基准 7 秒

    写风，漂游

    低速点缀形成局部光结，运笔牵流。持续笔势可延长这一阶段，上限约 15 秒。

  3. 约 5 秒

    慢慢，归形

    力与速度渐退，光回到花瓣。第一课要求留下笔迹并等花归来，取消半开比例密码。

漂游从破开完成时计时，不是每次松手重新等 7 秒。可以继续看花，也可以离开近景；不再靠第二次点击恢复。

进入世界之前

四种轮廓，五种光

改变花的形，
也改变光的性格。

百合的反卷、重莲的层叠、鸢尾的三立三垂、大丽的卷瓣放射，来自不同几何。花体与花尘共享系列配色，换色保留运动，换形迁移归形目标。

镜头跟着脚步，
手仍可以自由环看。

行走时镜头顺着实际方向转动；连续按同一方向不会随镜头自转绕圈。手动操作优先，停下来就保留视角。

桌面
WASD 行走，C 回正，滚轮缩放。近花直接拖动写风，右键环看；漫游中用 Space＋拖动或 R 风笔。
触屏
近花单指写风，双指拖动环看、张合缩放。双指期间取消主动笔势，避免把缩放结束当成投种或破花。
沉浸与节奏
全屏体验按钮／Alt+Enter；可关闭镜头随行、启用轻缓动态、静音与降低密度。打开模态面板或切到后台时暂停。

Ⅰ让春风经过触碰破开 → 留下一笔风 → 看它归形

只观看不会被误判通关；若没有写风，花归来后给出明确下一步。水边三处春痕逐步响应，完成后旧路亮起。衣橱里的形与光可以自由探索。

Ⅱ风中的回信按住牵引 → 绕过石心 → 在花杯旁松手

主风廊与侧庭使用同一方向的牵引。悬停只是观察；主动松手才承接。出界可回起点，已经通过的侧庭风门保留；游絮在这一幕后醒来。

Ⅲ借一段花桥脚下起笔 → 连过悬光 → 走到下一座石台

一份花尘只能借成一段路。先站稳中庭，再为彼岸织桥；未完成的笔画自然退回，承托着人的桥不能被收走。此处理解“保形”曾经保护过什么。

Ⅳ待寄出的春信拿起 → 亲自带去 → 种下 → 看清后再寄出

点按 E 即可拿取、安放与取回；手中种核可以存档。两种用途安排后，到启程台看一次摘要；取消不提交，启程后也能回到之前重新安排。

截图对应的实际构建、普通输入范围及中断记录见主线过程报告；静态图片本身不证明整条主线无故障。保留支线与最终发行检查另行记录。

你没有经历过这里的故乡

却愿意照料它留下的春天。
这一次，选择留给后来的人。

方舟替离乡者保留过一个春天。弥由修复花尘孕育，没有旧人的记忆；岑只留在旧记录里，游絮拥有自己的节奏。六段引言将这层关系交给玩家，三条物件支线与三座探索庭让它在杯声、字迹、护送和停步倾听中慢慢展开。

两枚种核，三种值得持续的生活现场的愿望选择后看见什么
旧日的灯让故乡的声音继续被听见蓝色听声环与提灯回应，寄出后光环展开
眼前的四季让这里的花重新生长、更替新芽出现，寄出后花簇继续铺开
远方的新庭让花帆带种子去往新的土地金色轨迹预示，寄出后种子飞向远处

两枚分别支持两种用途，形成《旧灯与新芽》《把故乡寄给远方》《春天不只一种形状》三封回信。没有隐藏第三核，没有高一级的“真结局”。自写杯曲会进入尾声；没有选择的愿望仍留在故事里。

杯曲、光刻、年份三条叙事支线，雨留、风过、潮生三座探索庭由 v5 延续。本轮重点重做花的循环、镜头、种子操作与地点可读性，不将已有内容算成六个新关卡。阅读全部动作、对白、成功与恢复条件 ↗

仍需要走得更深。

四种花型目前主要改变观感，尚未带来不同空间能力；主路仍线性，游絮没有自主任务，三种未来也尚未形成可持续游玩的新章节。

流晶的圆润厚度、石材层次、角色演技和声音表现仍有差距。现阶段是风格化实时交互章节；“电影级”与“3A”不是截图或构建成功自动带来的结论。后续玩法选择在剧本末尾明确标为未实施。
