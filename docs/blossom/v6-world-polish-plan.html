V6 寄信水岸与风廊局部美术实施方案

目标： 降低终庭的展品感，使灯、芽、帆在没有文字时也能读出不同用途；让风廊呈现长期被风塑造的地点性。

边界： 只修改 world.js 和新增 world-polish.js；不改变行走碰撞、三个用途的坐标、种核状态、交互和结局协议。原创程序几何与材质，不下载或购买资产。

取舍

保留现有小岛与关卡路径，改其建筑构图、表面层次、道具轮廓。扩大地图会引入未验证的碰撞和引导工作；单纯增加花草又不能解决三个奖杯同质和门柱挡住目标的问题，因此均不采用。

已确定的构图

  • 终庭拱门由入口 (-.8,-43.5) 移至后岸 (0,-49)，宽 9.8、高 5.6，较薄石带。脚点距圆心约 5.75，仍在半径 6 的岛面。返回方向也须由主相机遮挡系统处理，不能只验证首次进入。
  • memory(-3,-46) 为细框提灯和浅石座；season(0,-48) 为敞口种床和两片高低不一的嫩叶；voyage(3,-46) 为舟托、偏置桅杆与有体积的帆面。保留既有 petals/center/halo 动态节点。
  • 移除终庭完整同心装饰圈。岛面以灰绿湿石、暖砂通路、不规则苔土带区分材质；新增可行走表面起伏绝对量不超过 3 厘米。
  • 两侧及后岸成片植物与水蚀石，前岸植物低矮，中央入口与交互半径保持留白。不改变岛岸的实际碰撞轮廓。
  • 风廊保留光种起点 (-3,-14)、终点 (3,-18)、中央障碍和两条绕行线；景物放于边岸，避开 cinematic(-3.8,-17.5) 支线道具。

执行与验证

  • [x] 新模块集中处理岛面配色、三用途静态主体与岸边植被，材质共享，静态几何继续沿用 world 的按材质/空间合批，植物采用实例绘制。
  • [x] world.js 接入材质、arch 参数和环境 update，不引入新的状态来源。
  • [x] Node 验证构建、有限几何/矩阵、核心坐标不变、不同种核/结局状态可更新、dispose 幂等；记录新增 draw object 数量与几何规模。
  • [x] 获得根代理的独占 GPU 窗口后，在实际主游戏检查入口/返回/竖屏构图、三种用途轮廓、光种谜题两条路线无遮挡。实际截图才支持视觉验收，不以 CPU 测试替代。

需要根代理配合

相机从终庭远侧朝入口看时，后移拱门仍可能位于相机和用途之间。继续使用 cameraOccluders；根代理扩大视线采样至用途区域。竖屏相机距离和屏边提示由根代理统一处理。

CPU 验证记录

2026-11-19：node --test tests/world-polish.test.js tests/camera-occlusion.test.js tests/delivery.test.js，13/13 通过。单次 createWorld 约 384 毫秒；整个 world 130 个 mesh（含隐藏动态节点）、44 个材质、738 个实例，展开实例后三角形约 242536。这里的 mesh 数不是实际镜头 draw call 数，后者需 GPU 快照。178 个可见持有资源销毁各一次，再次 dispose 和 update 安全。

岸草/芦苇/湿石的根部最大半径 5.840002，距六个主要交互点的最小距离 1.74 米；土色浅岸片收在半径 5.95 内，防止平面漂浮到不可行走的水面。

  • evidence/v6-world-polish-04-wind.png：真实风廊近看，绕石两条线、出发花杯与落点都清楚；新布面和芦草在岸边，未占谜题路线。

最后一次风廊段 v6-world-polish-review.json 记录 0 pageerror；近看 render calls 431 / 1089618 triangles，入口继续视角 541 / 1373288 triangles，这是全游戏含渲染通道的实时统计，不能误写为新模块的独有开销。终庭前三张来自此前同一冻结源码的独立段，不混充为这份 wind-only 报告中的断言。

曾两次因验证脚本把原始存档坐标当成恢复后坐标而走向水面，已查清：存档记录支庭位置，但继续按既有恢复逻辑落在主风廊安全入口。最终脚本改为读取恢复后的实际位置再选路线，风廊近看成功。此事件不作为产品行走故障。

最后一次 CPU 修订与冻结

经根代理审阅实际截图，岸草下 11 片独立深色土片的硬边影响水岸连续感。最终版本删除这些浅片几何，将土色依据椭圆距离平滑混入既有岛面的顶点色；最高混合量 34%，边缘自然回到原石岸颜色，保留石岸法线和微起伏。整个方案保持不透明，不增加贴图、覆盖层或绘制批次。只有中央种床内部保留实体土面。

新增 CPU 断言：两个岛面各保持一个地表批次，材质不透明，顶点颜色与几何顶点一一对应。最后运行 world-polish / camera-occlusion / delivery 相关测试 14/14 通过（根代理同期已增加一项离轴花座遮挡测试）。详细场景数量、源码 SHA-256 和 CPU 验证时间见 evidence/v6-world-polish-cpu.json。

此修订后 world.js / world-polish.js 冻结，不再启动 GPU。上文截图代表土片优化前的构图版本；最终顶点色融合的外观应由根代理统一候选版实图验收，不能借用旧图声称已验证。
