这一次，手里的动作也不同

先观察，
再出发，最后表达。

花光让你调整物件与影子的关系；纸翼要求持续感受速度、方向与高度；春声让你决定哪些音符留下，哪里保持安静。三个章节共享来信与保存方式，各有自己的物体、规则和反馈。

这一轮把互动差异放进场景本身。完成并不立刻替你做决定：观察结果，读一读牵挂，再亲手留下回信。已经写好的信，也可以重访。

01 / 禾 · 种花的人

把故乡放进光里

抓住、移动、叠合。

三片透光花笺分别留着树、窗和花。移动时，幕上的投影跟着改变；顺着轮廓让它们相遇，花园逐层显现。判断来自前后位置与形状，不只靠辨别颜色。

完成后，选择留住窗前的树影，或让窗里开出新花。植物与投影的重点会改变，信里留下你保存时的摆放。

拖动花笺；1 2 3 选片，方向键移动，Shift 微调，Z 撤回。当前是三片花笺的有限空间谜题。

02 / 阿渡 · 修帆学徒

把信折成翅膀

抬翼、转向、借风。

纸翼主动起航后不断向前，近处风线、远处云层有不同的移动节奏。调整横向与高度，借上升气流，留一点余量应对侧风，穿过五道不同的风门。

偏航会回到上一段安全点，已过风门保留。抵达后可以点亮渡口灯火，或展开护种帆；选择变成场景里的物件。

拖动纸翼，或按住 WASD / 方向键；Space 缓行。触屏方向键可长按。暂停后需要主动继续起航，不设生命值与倒计时。

03 / 岑的旧杯声 · 游絮的此刻

写一段没有旧稿的春声

落音、留白、听一遍。

水岸悬着三排可辨形状的乐器，八拍留给你安排。点触或拖过乐器，加入、移走音符；听听密一些和疏一些的差别，也给回应留一点呼吸。

至少留下三个音符、两种声部，并完整听过当前版本，才能回信。修改后要重新听一遍；不按反应速度评分，也没有唯一标准旋律。

点触 / 拖奏；方向键选拍与声部，Enter 开关音符，Space 听奏，Z 撤回。固定音阶与八拍是当前表达范围。

回信之后，还可以带走

这份留影，
来自你真的做过的事。

  • 花光保存三片花笺的位置与树影／新花选择。
  • 纸翼保存通过风门的标记与抵达位置；不宣称记录了完整个人飞行轨迹。
  • 春声把真实三声部、八拍音符写成花谱，留白仍然留白。

来信册可在本机导出 SVG，春声还可按保存的谱面回听、逐拍高亮。修改草稿不会立即改写旧作品，重新提交后才更新。

“留一帧春光”另可导出风景或春信明信片。所有文件由玩家主动下载，不自动发布或发送。

让你的声音被听见

背景退后一步，
春声才有位置。

配乐使用本地乐器采样与原创编排。摆放、穿门、落音、脚步和织桥各有动作回应；进入春声创作时，背景配乐淡出，让音符与停顿更清楚。

来信册播放保存的真实谱面，关闭或停止会取消后续音符。配乐、动作音效与环境声可独立调节，创作乐器由动作音效音量控制。

进入本机花庭 ↗完整操作说明

在游戏目录双击“启动春信.cmd”；需本机已有免费 Node.js。也可运行 node scripts/serve.cjs --open，默认地址为127.0.0.1:5192。不要直接双击dist/index.html；保持服务窗口开启。

旧回信保留原有文字与选择，新体验不会被自动标记完成。当前浏览器、网址各自保存；可在设置中导出／预览导入。不同端口或设备不会自动同步。

实现、证据与真实限制

当前实现

  • 三片花笺的空间摆放、五道风门的连续控制、三声部八拍的真实编排。
  • 主动回信、环境后果、草稿与已提交作品分开保存，旧回信与已寄快照保留。
  • SVG作品留影、保存谱面回听、本地存档与明信片、可选追风及原有物件支线。

仍需验证与深化

  • 固定暗房与航段仍有内容边界，不是无限创作或开放世界。
  • 首次复杂材质准备可能停顿，未承诺全部设备全程60fps；浏览器仿真不替代实体设备。
  • 叙事记忆、自然完成时长、复玩动力与分享意愿需要陌生玩家观察，商业用户群尚未被验证。
