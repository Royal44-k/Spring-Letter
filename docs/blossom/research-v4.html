《花漾年华：待寄出的春信》——第四轮第一方案例与免费素材研究

研究日期：2026-11-18。目标是让开场有情境、身份可读、支线能玩、花与花尘连续转化，并为灰白场景增加克制的表面细节。

本轮沿已有设计资料的来源链继续找作者作品与官方制作说明，不重复 research-sites-v3.md 对 Showreel、SAEL、MotionSites 的目录调查。下文严格区分实际读取的材料、设计推论和采用决策。没有把网页文本读取说成试玩，没有把商业游戏画面当成免费素材，也没有把“电影感”或“AAA”当成已经达到的结果。此前 Fable 5.2 传播案例的核验继续以 research-cases.md 与 fps-case-v3.md 为准。

1. 四个新的一手案例：把“看起来很美”落实为玩家的行动

1.1 Amanita《Samorost 3》：身份、工具、动机在同一个行动中成立

已观察。 官方项目页明确将主角设定为好奇的太空小精灵，借魔笛穿越宇宙、追寻其神秘来源，并把挑战、生物、惊喜与声音放在九个世界的探索中。此次读取了项目说明，未试玩或完整观看预告。Amanita 官方项目页

推论。 角色不必先靠一段身份说明才被理解。玩家使用的第一种能力，可以同时说明“我是谁、为何来到这里、怎样改变这里”。音乐或花尘也可以是沟通工具，而不只是气氛。

采用决策。 开场先让弥靠近一件有人使用过的日常物；第一次唤醒操作产生花尘、物体回应和一句有指向的字幕。身份“送春者”随结果出现。建议句式为“我是弥。替没能抵达的春天，走完最后一程。”身份最终措辞由完整脚本统一。大世界史留在发现之后。

1.2 Amanita《Creaks》：先有一个可感知的异常，再有宏大世界

已观察。 官方开场介绍从地面震动、灯泡破裂、墙后异响进入地下世界，接着才说明鸟形居民和貌似危险的家具怪物。官方同时提供 Creaksbox 生成式配乐网页；已读其入口，但该页要求桌面浏览器，本轮没有实际操作音轨。Creaks 官方项目页、Creaksbox 官方网页

推论。 具体失常比抽象背景更快形成悬念：“没有风，信却翻了一页”比“世界的季节已经崩坏”更适合首次观看。异常应指向玩家能接近的对象。

采用决策。 开场用一枚漂浮但不前行的花瓣、一圈只完成半边的涟漪，或迟到一拍的回声建立“春信尚未寄出”。它应在第一次互动后改变，而不是永远播放的开场装饰。只借叙事结构，不复用角色、图片、配乐或家具谜题。

1.3 Matt Nava / Giant Squid《Sword of the Sea》：恢复世界必须改变可玩空间

已观察。 创意总监 Matt Nava 的作者文章把高速流动、探索遗迹、发现秘密、恢复海洋联系起来：沙地变成海面，海带林提供新的到达高度，鱼群与海洋生物参与恢复后的世界。已读取作者文章，未试玩商业游戏。Matt Nava 的第一方制作介绍，2025-06-04

推论。 “我修好了这里”应当改变玩家的下一种行动。单纯增加饱和度、展示完成提示或多一篇日志，很快就会失去恢复世界的分量。

采用决策。 支线至少有一个空间或行为回报：一枚回信让伴行游絮学会新动作；修复一处回声让另一处隐蔽物有可听见的线索；一簇花恢复后形成短暂观景路径。主线可直接继续，额外探索会改变结尾画面中的细节。小体量章节先做三种不同反馈，不用重复同一种收集动作填密度。

1.4 Joseph Santamaria：镜头位置、注视目标、文字节拍需要分别编排

已观察。 作者教程把相机位置与 look-at 目标分别存储，再用同一时间线驱动两者；文字有独立显隐区间，雾、光、摄影机构图共同组织章节。教程另一个示例让粒子线条的不透明度响应运动速度。直接打开返回 403；本轮实际读取的是搜索工具返回的作者文章索引正文与代码，未运行示例。作者教程，2025-11-19

推论。 电影感主要来自“此刻在看什么、何时给玩家下一条信息”。将所有系统用同一速率淡入，并不能得到清晰的镜头。位置与目标分离可以先看信，再抬眼发现身后的世界。

采用决策。 开场以同一实时场景完成三个短节拍：物件近景 → 弥与游絮的关系 → 可探索的水面和遗构。每段只承担一个信息重点；相机归还玩家前须落在稳定可玩的构图上。不要把网页的 500vh/900vh 滚动长度和滚动劫持搬进游戏；用现有时间状态机即可，无需额外框架或付费组件。

2. 两条继续追到作者的线索

2.1 Bruno Simon 2025 作品集：本轮补到具体输入、恢复机制与开放音乐

已观察。 旧报告已有 Bruno 的大方向；这次读取当前站的具体操作表：交互、刹车、跳跃、地图、重生、静音与画质设置，另有竞速、秘密和成就；作者明确链接 2025 源码仓库，并说明源码 MIT、音乐 CC0。音乐目录另有独立 CC0 文本。没有驾驶试玩，也未核验联网成绩服务。当前作者站、2025 作者仓库、独立音乐许可

推论。 支线密度来自不同短活动与可靠恢复。一次无法退出的交互或一段难懂的输入，会压过很多美术细节。

采用决策。 保留明确的交互提示与恢复入口；全屏按钮必须可退出并同步真实浏览器状态。新增支线应复用已经学会的输入，但改变观察/顺序/时机要求。音乐先登记候选，未试听判断，不进入本次首包。

2.2 Pavel Mazhuga 作者实验室：将“形状变化”与“自由运动”分开审视

已观察。 由 Codrops 作者目录追到其本人 Lab，列有 WebGPU/TSL 的 Particles noised morphing、Mesh particles destruction、Dissolve，以及 WebGL 的 FBO particles morphing、Particles on model surface；具体 morphing 页面可读入口仅为 Click。本轮没有看到完整动态图，也未查到这些演示的明确复用许可，不能据此宣称它们的成片效果或复制源码。作者实验室、具体 morphing 演示入口

推论。 这条来源能确认作者把表面采样、变形、溶解、自由运动分别研究；不足以证明其实现可直接套用。对本项目，更有价值的是保持现有真实花面采样数据，避免凭演示标题重写技术栈。

采用决策。 沿用当前 WebGL2 粒子管线。花→尘→路径→花的每一段都保留可追踪的源位置与目标位置；新增扰动仅作用在中间过程，收束阶段应逐渐减弱。必要时只做少量引导粒子带出方向。该段为本项目的设计推论，尚需逐帧比对两段用户参考后才能判定视觉一致性。

3. 免费素材：一项实际采用，一项候选保留

3.1 已下载并核验：Poly Haven / Rob Tuytel — White Plaster 02

观察。 官方页标识 CC0、白色平整石膏材质，原始尺度横向约 1 米，提供 OpenGL 法线与粗糙度。官方 API 给出每个文件的精确字节数、URL 与 MD5。素材页、官方文件 API、Poly Haven 许可

文件官方直接文件精确字节验证结果
1K OpenGL normalwhite_plaster_02_nor_gl_1k.jpg652,310Pillow 完整解码 JPEG、1024×1024、RGB；MD5 符合 API
1K roughnesswhite_plaster_02_rough_1k.jpg295,900Pillow 完整解码 JPEG、1024×1024、L；MD5 符合 API

推论。 当前灰白场景需要材料细节，但不需要强烈大理石纹理与花争夺注意。只增加微法线和粗糙度，可保留原创色彩设计。该判断来自项目现状与官方材质描述，最终强度仍需在实际画面检查。

采用决策。 按主实现任务决定，已将这两张图下载至 spring-letter/public/assets/surfaces/，没有下载底色、位移或高分辨率包。起始法线强度约 0.12，仅用在石台、拱等建筑材质。两图新增传输 948,210 B，约 0.90 MiB；若两张以 RGBA8 + mipmap 上传，显存预算约 10.7 MiB，属于估算。纹理应使用数据色彩空间；保持原有材质作为加载失败回退。首包目标仍由总构建结果验证，不能用新增素材大小代替总大小。

存档：spring-letter/public/assets/surfaces/source.json 保存官方地址、许可、尺寸、SHA-256、MD5；README.md 保存使用范围；CC0-1.0.txt 保存许可原文。官方全量 API 元数据另存 docs/blossom/white-plaster-02-metadata.json。下载文件并完整解码已完成，游戏运行时整合由主实现任务负责，本研究未改 main/world。

3.2 已核许可、未采用：Kounine — Sudo

观察。 Bruno 当前作者站将配乐作者列为 Kounine，并明确声明音乐 CC0。链接指向其源码中的独立音乐目录，其 license.md 为 CC0 1.0。GitHub 官方内容 API 报告 Sudo.mp3 为 6,173,760 B，Sudo.wav 为 44,431,636 B。本轮未下载、未试听，不评价旋律与情绪是否适合。音乐目录、许可原文、官方文件元数据、明确文件地址

推论。 免费并不等于适用。完整 MP3 已超过当前章节新增素材预算，也未证明能支持春信的沉静、亲密情绪。

采用决策。 本轮 0 B 纳入游戏，继续保留现有程序化声音。未来只有试听适合、确定可循环段落、完成响度与授权登记后才讨论裁切/压缩，不为增加“素材数量”而使用它。

5. 留下可复用的学习方法

每次从聚合站出发，只保留有明确用途的作者链：目录 → 作者作品/作者文章 → 可复用源码或资产许可 → 明确文件与预算 → 小范围画面验证 → 是否采用。商业作品可以提供叙事、构图、交互研究；素材复用需要另有明确许可。教程被 403 拦截时，标记实际读取的索引正文，不能编造“已运行”或“已观看”。

本次具体增量是四个新的一手设计案例、一个更新的浏览器游戏化作品来源、一条待视觉验证的作者粒子实验线，以及一组完成下载/解码/散列验证的 CC0 微表面贴图。下一轮不再扩充目录数量，先用实际开场和三种支线验证这些方法是否让玩家理解、愿意操作且愿意停留。
