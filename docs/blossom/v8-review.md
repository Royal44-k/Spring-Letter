## 跨模块检查结果

- **恢复位置**：startGame 先恢复规则，再用实际 `terrainAt` 检查原位置。合法固定地面恢复原坐标；桥上不恢复临时承托位置，仍返回安全石台。这比直接信任外部坐标稳妥。
- **侧庭往返**：在 Node 中调用真实 `createLandscape().supportAt()` 验证 rain(-12,1.5)、wind(12,-13.5)、tide(-12,-26.5) 均有合法地面，分别是 garden / wind / pool（R）。没有用传送注入作通关证据；这些只是落点数学检查。
- **交互优先级**：正在进行的追风保留 E；可执行的种核拿起/安放优先；自由漫游近信台可读信。已增加实际生产 `requestInteraction` 函数的 VM 检查。
- **导入对话框**：文件先受 1 MiB 限制、验证、摘要预览，再确认写入。取消或读文件过程中关闭不会产生晚到导入；预览期间另一页保存会阻断替换。所有用户文件内容只入 textContent，模板为本地固定文本。
- **新回信快照**：commitLetter 使用独立 restoreLetters 结果冻结寄出时的选择；后来重排叶脉不会改写该快照。规则模型的旧版本 fallback 合理，但入口必须在它之前拒绝未知 schema，现服务已经这样处理。
- **引导隔离**：序章结束已指向左岸来信，中心花不再自动抢镜；letter-led 隐藏旧 HUD/world-guide。是否真的清楚，仍须完整首次体验检验，不能只以 CSS 存在作结论。
