# v8 audio source research — 2026-11-21

Adopted only anonymously downloadable, explicitly CC0 material. No account, payment, subscription, generated soundtrack or paid library was used.

1. **Kenney — Impact Sounds**, https://kenney.nl/assets/impact-sounds. The current live page offers 130 files under CC0 and a “Continue without donating...” action. Its old static ZIP link now redirects to the page. The live page's ordinary download function obtains a signed link from `/download-link/6173736574732f696d706163742d736f756e6473`; the same public page session was used. `kenney-download-response.json` records that response. `kenney_impact-sounds.zip` contains the author's `License.txt`. Adopted six footstep variants and a short mining contact. Concrete is mapped to the game's stone paths; mining contact is a tactile abstraction, not a recorded rotary mechanism.
2. **isaiah658 — Ambient Bird Sounds**, https://opengameart.org/content/ambient-bird-sounds. The author describes a camera microphone field recording and Audacity cleaning. Page explicitly offers CC0 and says attribution is appreciated but unnecessary. File link on the live page is `https://opengameart.org/sites/default/files/birds-isaiah658_0.ogg`, 544,669 bytes. This smaller recording was selected instead of a 2.7 MB bird archive or an 86 MB park bird file.
3. **Thimras — Park ambiences**, https://opengameart.org/content/park-ambiences. The author describes three field recordings in Adelaide, South Australia, at 48 kHz under CC0. The river recording features water flowing over a low step and wildlife. Direct file: `https://opengameart.org/sites/default/files/park_ambience_river.wav`, expected 99,072,736 bytes. Only this river original was downloaded; the other large park files were not. `thimras.html` records the public profile associating the author with Eike Germann.

The web search renderer returned 403 for the OpenGameArt pages; an ordinary anonymous HTTPS request from the workspace returned the full source pages and their offered downloads. No login, challenge or access restriction was bypassed. Four saved HTML pages and the actual original bytes preserve one-hand authorship/license evidence. Local derived-file provenance is `spring-letter/public/assets/foley-v8/sources.json`.

`process_audio.py` uses the local Python runtime with PyAV 19.0.2 / NumPy 2.3.5. It converts to mono 22,050 Hz PCM16 WAV, trims one-shots with short edge fades, and makes two 20-second ambient loops using 2-second equal-power overlaps from 22-second excerpts. It removes DC offset and scales signal levels within peak limits. Nothing is synthesized into the adopted recordings. The script refuses final hashing while the river download is incomplete.

The original audio-engine noise remains only as subtle wind and a graceful failed-load fallback for one-shots. Recorded bird and river loops replace the old synthetic birds and water. Original music remains the existing composed VSCO chamber score.

Validation: `node --test tests/audio-v7.test.js tests/audio-v8.test.js` covers local URL resolution, scheduling, mixer independence, terrain variation, stone contact, pause/mute, bounded source counts and disposal. Signal measurements and full decode verification accompany the manifest. No perceptual listening is claimed, and no GPU browser was started by this task.
