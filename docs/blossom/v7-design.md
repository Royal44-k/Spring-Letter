# 花漾年华 · 风起之时（0.5）

2026-11-20。针对试玩反馈：任务能通关不等于好玩，画面参数和测试数量不等于审美，提示音不等于配乐。保留独立主题、花体与花尘、探索和寄信的内容，改变玩家在空间中做什么。

## 设计选择

采用「追风送春」而非继续增加花朵按钮或堆叠更长文本。弥以花尘为伴，把漂泊花灵送回庭院。按住踏风加速消耗气息，放缓脚步恢复；连续接住花灵得到连锁，稳妥路线与较难的高收益路线需要取舍。初庭、风廊和终庭分别安排活动，允许失误、重试与比较个人记录。首次完成初庭活动亦唤醒旧路，原先花尘练习仍有效，避免旧存档和偏爱慢游的玩家被强迫计时。

音乐必须可辨认：有主题、和声、句法、收束与场景差异；由庭院、花尘、追风、渡桥、寄信状态决定配器，行动声音与环境层分开。支持独立音乐/音效音量、静音、失焦暂停，不伪称真人演奏或管弦录音。

美术方向：晨雾水庭，青绿植被、暖白石与蜜色侧光，少量珊瑚花色；近景有真实表面，远景有空间分层。默认主花为粉瓷，参考视频的月银虹彩作为可选系列保留。植被以群落合批组织，环境动景服务风向与路线，不能挡住玩法。

## 成功标准

- 玩家能在起始庭看见活动入口、明白移动与踏风用途，尝试后知道怎样提高成绩。
- 失败不毁主线，重试不重复序章；途中暂停、离开、切回存档不出现重复奖励。
- 能听到完整乐句与行动差异；音乐切换不中断成突兀噪声；静音/暂停真实生效。
- 新旧同机实景截图可辨认材质、光照与层次改变，兼顾性能。
- 通过新活动普通输入、旧主线回归、音频实际输出/录制、截图与合理持续运行验证。
