# 花漾年华：待寄出的春信 · 制作档案

当前游戏版本为 **0.7.1**；设计记录沿用 **v9**，渲染修复与验证使用 **v10** 编号，更新于 2026-11-21。本作是独立主题，与金沙项目无关；《花尘之间》是前期工作名。

本轮将三庭重复的转轮流路改为 **摆放花影、连续渡风、编排春声**。花卉与花尘仍是视觉线索，三个章节分别使用空间观察、持续操控与声音表达。人物、回信选择和可带走的实际作品连接这些行动。

0.7.1 修复开场粉屏、首帧阴影、图形中断后的存档救援和终章提示遮挡。[根因与正负对照](../../spring-letter/evidence/v10/render-root-cause.md)及[最终验证](../../spring-letter/FINAL_QA.md)保留完整证据。

## 这一版实际留下什么

花光暗房可以连续拖动三片透光花笺，按轮廓完成显影，并选择留下树影或新花。纸翼渡风需要主动起航，连续控制左右与升降，经过五道不同位置与形态的风门；偏航回安全段，先前进度保留。回声织信支持三种乐器、八拍谱面、拖奏、删除、撤回与完整试听；至少三个音符、两种声部并听完当前谱面后才能回信。

来信册根据已提交作品生成 SVG：花光保留真实摆放，纸翼保留通过标记与抵达位置，春声保留实际音符和留白。春声还可按保存的谱面回听。创作时背景配乐让位于玩家的声音；其他行动由本地动作音效回应。SVG、存档与明信片在本机导出，不自动对外发布。

新体验使用独立草稿与完成记录。旧版已回信的选择和文字继续保留，不会被改写成新玩法的历史，也不会自动完成三项新体验；玩家重新完成并提交后才更新那封回信。已寄出的结尾保留寄出时的作品快照。

这些实现仍有明确边界：花光不是任意光线追踪或无限造景，纸翼不是开放世界自由飞行，春声不是完整作曲软件。电影／AAA 质感、充分的复玩动力、目标玩家兴趣与商业可行性仍需要更多内容打磨和真人证据，不能由自动化数量、制作时长或模块数量证明。
